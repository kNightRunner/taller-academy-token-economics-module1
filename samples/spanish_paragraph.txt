Un proyecto pequeño y seguro en Python para el Día 1 — Fundamentos de Becoming a Forward Deployed Engineer. Utiliza el ejemplo de factura ficticia del curso y agrega experimentos para comparar una llamada simple al modelo con un agente que puede consultar herramientas confiables de Python para obtener datos. Es un proyecto de aprendizaje ejecutable, no un servicio financiero de producción. No requiere datos de clientes, una base de datos ni una API de pago si se utiliza Ollama.
